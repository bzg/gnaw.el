=gnaw.el= lets you browse and manage [[https://codeberg.org/bzg/bone][BONE]] reports from Emacs.

BONE (/Backlog Of Notable Emails/) is a bug tracker that never asks
anyone to file a bug: it turns the =[BUG]=, =[PATCH]= or =[FR]= mails of a
mailing list into reports and publishes them as plain =reports.json=
files (see [[https://bzg.fr/en/notes/the-issue-with-issue-trackers/][The issue with issue trackers]]).

=M-x gnaw= lists the reports of the sources you follow: search them,
read their emails, view or apply their patches, and mark them sticky
or dismissed. =gnaw.el= is also the data layer of the [[https://codeberg.org/bzg/gnus-gnaw][gnus-gnaw]],
[[https://codeberg.org/bzg/notmuch-gnaw][notmuch-gnaw]] and [[https://codeberg.org/bzg/mu4e-gnaw][mu4e-gnaw]] mail front-ends.

* Installation

=gnaw.el= requires Emacs 28.1 or later. On Emacs 30 or later, install it
with =package-vc=, along with its Info manual (=C-h i m gnaw RET=):

#+begin_src emacs-lisp
(use-package gnaw
  :init
  (unless (package-installed-p 'gnaw)
    (package-vc-install
     '(gnaw :url "https://codeberg.org/bzg/gnaw.el"
            :doc "doc/gnaw.org"))))
#+end_src

Update later with =M-x package-vc-upgrade RET gnaw RET=.

* Getting started

=M-x gnaw= opens the report browser. On the first run, it asks for a
source URL, the local git repositories where its patches apply, and
how to open report mail; =M-x gnaw-configure= reruns this setup.

For example, to read the [[https://tracker.orgmode.org][Org mode reports]], give it this URL:

: https://tracker.orgmode.org/reports/all-open.json

or write =~/.config/gnaw/config.edn= directly:

#+begin_src clojure
{:sources [{:urls ["https://tracker.orgmode.org/reports/all-open.json"]
            :name "Org mode ML"
            :repo "~/src/org-mode"}]}
#+end_src

In the browser, =h= lists all the key bindings and =/= filters the list
with =key:value= tokens.

* Documentation

The [[file:doc/gnaw.org][Gnaw manual]] covers everything else. Build it with =make info= or
=make pdf= (this needs Emacs 29 or later, =makeinfo= and =texi2pdf=).
